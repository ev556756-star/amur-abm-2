# ABM 2.0 — интерактивный прототип

## Запуск на компьютере

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Публикация постоянной ссылки

1. Распакуйте архив в репозиторий GitHub (все CSV и GeoJSON должны лежать рядом с `app.py`).
2. Откройте https://share.streamlit.io/ и войдите через GitHub.
3. Создайте приложение, выбрав репозиторий, ветку `main` и главный файл `app.py`.
4. После развёртывания Streamlit выдаст общедоступную ссылку.

## Ограничения

- Текущее значение 753 200 в 2036 г. — результат предыдущего калиброванного прогона, а не нового расчёта проектных эффектов.
- Сценарии пока не переключаются: загружен первый расчётный блок `ии3.xlsx`.
- Однолетние возраста не сохранены в предыдущем экспорте ABM.
- Геометрия границ преобразована из EPSG:3857 в EPSG:4326.
- Координаты отдельных проектов отсутствуют; не отображаются фиктивные маркеры.
- Выгружены 349 распознанных проектных записей (в сводке книги 352); требуется сверка 3 записей.
- Цвета: медицинские #00AEFF, немедицинские #F02A91.
